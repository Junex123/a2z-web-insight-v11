# PROJECT_STATE.md

This project's operational state file is **`PROJECT_PROGRESS.md`** (same
directory). It has served this exact role since the project's first
session - current phase, test counts, typecheck result, exact files
changed, architectural decisions, known/security limitations, and the
next task - so a second, separate `PROJECT_STATE.md` was not created
alongside it (this project's own convention throughout is: don't build
a parallel structure when an existing one already does the job).

Read `PROJECT_PROGRESS.md`. It is authoritative.
